# Профили должностей

Справочник карьеры программистов 1С. В нём лестница должностей, профиль каждой заполненной должности и планы развития людей.

Должность — роль на лестнице, не человек. У должности может быть профиль: навыки и обязанности с ожидаемым уровнем и проверяемым критерием.

Сотруднику назначают должность. Отдельной оценки его личных навыков нет.

Индивидуальный план развития — отдельный документ на период: какие компетенции подтянуть до планки целевой должности и какие задания это подтверждают.

Без входа можно смотреть схему должностей, профили и сравнение двух профилей. После входа сотрудник видит свою должность и свои планы. Руководитель ведёт прямых подчинённых и их планы. Админ правит справочник и людей.

## Запуск

Нужен Node.js 24.

```
copy .env.example .env.local
npm install
npm run db:seed
npm run dev
```

В `.env.local` задайте `ADMIN_PASSWORD` и длинный случайный `SESSION_SECRET`. Пустые значения и заглушки `change-me` приложение не принимает. Пока в базе нет администратора, пароль из файла создаёт первого. После этого входят логином сотрудника.

Открыть http://127.0.0.1:3000 . База — `data/profiles.sqlite`, в git её нет. Пароли тоже остаются только на машине, где запущено приложение.

Выкладка на сервер Windows: [docs/deploy-iis.md](docs/deploy-iis.md). Повторное обновление уже выложенного сайта: [docs/update-server.md](docs/update-server.md).
