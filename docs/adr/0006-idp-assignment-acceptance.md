# Задание ИПР принимают в строке плана

ИПР как список компетенций из разрыва нельзя выполнить и проверить: нет конкретного действия. Свободный текст без компетенции отрывает план от справочника должностей.

Строка плана — задание из общего справочника, привязанное к одной компетенции из пула разрыва. В справочнике обязательны название, «узнать» и «проверить». В документ копируют эти тексты; в этом ИПР их можно уточнить. Несколько заданий на одну компетенцию группируют в карточке. Руководитель принимает задание в той же строке — это подтверждение компетенции; если заданий несколько, компетенция подтверждена, когда приняты все. Отдельного «вернуть» нет: пока не приняли, строка просто не принята. Сотрудник двигает ход до приёмки; после приёмки не трогает. Руководитель может принять сразу и снять приёмку (в том числе у уже выполненного плана — тогда план снова активен).

Скрытое задание в новые планы не предлагается. Типы курса/теста и минуты из черновика УПО в этот шаг не входят.
