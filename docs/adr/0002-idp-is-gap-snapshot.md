# ИПР копирует разрыв, а не следит за справочником

«Что нужно для перехода» можно было считать живым `/compare` двух должностей. ИПР вместо этого хранит снимок: целевая должность — планка, пул компетенций берётся из разрыва на дату открытия (обязанности в пул не входят). Текущая и целевая должности на карточке не плывут, если сотруднику потом назначили другую должность. Если у текущей должности нет профиля, её считают пустой, и пул — компетенции цели.

Повышение на целевую должность ИПР не закрывает: выполнен только когда приняты все задания плана. Назначение другой должности активный ИПР не трогает. «Обновить разрыв» дописывает в пул новые компетенции, строки заданий не удаляет и не добавляет.

Тексты задания в строке — копия справочника на момент добавления; правка справочника чужие планы не меняет.

ИПР — отдельный документ, не раздел карточки сотрудника: список, адрес и кто видит планы — в `0005`. Задания и приёмка — в `0006`.
