# ИПР копирует разрыв, а не следит за справочником

«Что нужно для перехода» можно было считать живым `/compare` двух должностей. ИПР вместо этого хранит снимок разрыва: пункты не плывут после правки seed. Если у текущей должности нет профиля, её считают пустой, и в снимок входит весь профиль цели.

Когда сотруднику ставят должность-цель, ИПР становится выполненным, даже если пункты не закрыты: повышение — факт, а не процент отметок. Назначение другой должности активный ИПР не трогает. Обновление снимка сливает пункты по компетенции (статус сохраняется, исчезнувшие выкидываются, новые — «не начат»); свободные пункты не трогает.
