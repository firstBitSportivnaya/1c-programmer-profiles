# ИПР — документ, не раздел сотрудника

План можно было править только на карточке человека. Тогда «все ИПР» превращались в список людей, а открытие плана вело в сотрудника.

ИПР — отдельный документ со своим адресом: список `/idps`, карточка `/idps/{id}`. Поля документа: сотрудник, текущая должность на момент открытия, целевая должность, кто создал. Пункты, снимок разрыва, статусы и закрытие живут на карточке плана. Создают план из списка ИПР (сотрудник + цель), не из карточки человека. Кабинет и карточка сотрудника только ссылаются на документ.

Кто видит список: админ — все планы; руководитель — свои и планы прямых подчинённых; остальные — только свои. Завести план может руководитель этого сотрудника или админ. Сам себе план сотрудник не открывает. «Создал» — сотрудник, который нажал «Создать»; это поле не плывёт, если потом сменили руководителя.

Один активный ИПР на сотрудника и снимок разрыва — в `0002`. Оргсвязь и судьба плана при смене руководителя — в `0003`.
