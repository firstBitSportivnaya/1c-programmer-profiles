# Сотрудники входят логинами, каталог открыт без входа

Справочник должностей должен остаться читаемым без учётки — как сейчас. Кабинет (текущая должность, ИПР) — только после входа сотрудника. Админ — признак на сотруднике, не отдельная должность и не общий «режим правки» без человека.

Как появляется первый админ и когда общий пароль из окружения перестаёт пускать в систему — в `docs/engineering-decisions.md`.
