# Сотрудники входят логинами, каталог открыт без входа

Справочник должностей должен остаться читаемым без учётки — как сейчас. Кабинет после входа — текущая должность и ссылки на свои ИПР. Редактор плана — карточка документа `/idps/{id}`, не кабинет. Админ — признак на сотруднике, не отдельная должность и не общий «режим правки» без человека.

Вход, выход и создание первого админа — обычный POST `/api/session` (cookie на ответе и редирект). Server action с `useActionState` и `redirect` для этого не использовать: форма зависает на «входим». Как появляется первый админ и когда пароль из окружения перестаёт пускать — в `docs/engineering-decisions.md`. ИПР как отдельный документ — в `0005`.
