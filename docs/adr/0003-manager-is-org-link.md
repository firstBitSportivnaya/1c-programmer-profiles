# Руководитель — оргсвязь, не должность

На графе есть «руководитель команды разработки», но людьми может руководить и ведущий. Руководитель — связь между сотрудниками, не вывод из должности. У сотрудника не больше одного руководителя; ссылка на себя и циклы (A→B→A) запрещены.

Руководитель видит прямых подчинённых и ведёт их должность; ИПР этих людей — отдельные документы, которые он может создавать и вести. Админ — любого. Документ привязан к сотруднику полем, не вложен в карточку: если руководителя сняли или деактивировали, подчинённые остаются без него, планы не переезжают. Деактивация сотрудника отменяет его активный ИПР; документ остаётся в истории.
