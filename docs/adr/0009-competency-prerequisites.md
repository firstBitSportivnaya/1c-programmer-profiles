# Дерево навыков строится по редакционным предпосылкам, один родитель

Справочник хранит компетенции в 9 группах-разделах, глубина дерева ограничена единицей, а уровень 1–3 задаёт требование должности. Связи «этот навык нужен раньше того» в данных нет: ни группа, ни лестница должностей её не выражают. Первая версия холста рисовала рёбрами ход ИПР от карточки должности к каждому узлу. Линии шли через чужие узлы и читались как несуществующие цепочки.

Дерево навыков строится по отдельному редакционному списку предпосылок: у каждого навыка не больше одного родителя. Ребро «родитель → навык» означает порядок роста, а не требование и не ограничение доступа: пометку можно ставить независимо от предпосылок. Список ведётся в `src/lib/skill-tree-graph.ts` рядом с раскладкой и не выводится из групп, разрыва, пула, уровня или порядка строк профиля.

## Правила

- Граф — лес: шесть корней, у узла ровно один родитель, циклов нет. Покрытие, корни и циклы проверяет `npm run check:seed` по `seed/data.json`.
- Предпосылки не влияют на пометку, разрыв, ИПР, приёмку и ачивки (ADR 0001, 0006, 0007). Ребро — только визуальный порядок.
- Пометка остаётся дискретной и не превращается в уровень: планка на узле — требование должности (ADR 0001, 0007).
- Холст личный и показывает всё дерево. Слои считаются по глубине предпосылок: ребро всегда между соседними слоями, поэтому линия не проходит через узлы.
- По умолчанию открыт отбор «Мои»: навыки текущей должности, цель активного ИПР и их предки. Полное дерево — по переключателю.
- Навыки и пометки вне текущей должности и цели — отдельная группа «Вне профиля» (ADR 0008).
- Состояние шага плана — значок на узле, не ребро. Ребро не означает «принято» или «в работе».

## Отказ

Автоматически выводить предпосылки из групп справочника или из появления навыка в профилях должностей. Группа — раздел, а не родитель. Лестница должностей говорит, когда навык требуется, но не какой навык нужен раньше. Такое дерево снова даёт ложные стрелки.

## Проверка

`npm run check:seed` — покрытие: каждый навык стоит в дереве, у навыка один родитель, циклов нет, состав корней совпадает с редакционным. e2e: ребро идёт только от родителя к навыку на слой ниже, узел без строк плана показывает значок, а не цвет ребра.
