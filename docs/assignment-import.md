# Файл загрузки заданий ИПР

Для агента, который собирает задания и тесты в Excel. Загрузка — у админа на `/assignments`, кнопка «Загрузить». Книгу собирает команда ниже, не руками и не другим генератором таблиц.

Файл книги в git не класть.

## Команды

Из корня репозитория.

Список компетенций поставки, без обязанностей. Колонки: идентификатор, тип, название.

```
npm run assignments:xlsx -- --catalog
```

Это `seed/data.json`. Компетенцию, которую добавили уже в базе, отсюда не видно: идентификатор брать из адреса карточки `/admin/competencies/{id}`. В файл писать идентификатор, не название.

Собрать книгу и проверить её тем же разбором, что и загрузка. При ошибке файл не создаётся.

```
npm run assignments:xlsx -- tmp/assignments.json tmp/assignments.xlsx
```

Готовый `tmp/assignments.xlsx` админ загружает на `/assignments`.

## JSON

Массив или объект с полем `assignments`.

```json
{
  "assignments": [
    {
      "competencyId": "comp-...",
      "name": "Название задания",
      "learnText": "Что изучить",
      "verifyText": "Чем подтвердить",
      "questions": [
        {
          "prompt": "Текст вопроса",
          "options": [
            { "text": "Верный ответ", "correct": true },
            { "text": "Неверный ответ", "correct": false }
          ]
        }
      ]
    }
  ]
}
```

Без теста поле `questions` опустить или оставить пустым. Тогда в книге одна строка задания с пустыми «Вопрос», «Вариант» и «Верный».

`correct` — только `true` или `false`, не строки «да» и «нет». В книгу команда сама пишет «да» и «нет».

## Что попадает в книгу

Первая строка первой страницы, строго в этом порядке:

`Компетенция`, `Задание`, `Узнать`, `Проверить`, `Вопрос`, `Вариант`, `Верный`. Восьмая колонка `Уровень` необязательна.

Дальше одна строка на вариант ответа. У всех строк одного задания одинаковые компетенция, название, «узнать» и «проверить». Название и текст вопроса сравниваются без учёта регистра: разный регистр — это одно задание и один вопрос, в книгу попадает написание из первой строки JSON.

У вопроса не меньше двух вариантов и ровно один с `"correct": true`.

В JSON поле `level` — `1`, `2`, `3` или `null`. Если поля нет, колонка «Уровень» в книгу не пишется и загрузка уровень не меняет. Пустая ячейка тоже не меняет уже заданный уровень. Новое задание без уровня в план не предлагается, пока уровень не поставят на карточке.

## Чего файл не делает

- Не принимает обязанность (`duty`) и неизвестный идентификатор. Задание справочника к обязанности не крепится.
- Не трогает скрытое задание с тем же названием в той же компетенции и не создаёт рядом второе. В итоге загрузки скрытое только называют.
- Не меняет строки уже открытых ИПР: у них свой снимок текстов и вопросов.
- Не обновляет задания, которых в файле нет.

Любая ошибка файла отменяет запись целиком: пустое название, пустые «узнать» или «проверить», вопрос без двух вариантов или без ровно одного верного, уровень не из 1, 2, 3.

Повторная загрузка активного задания с тем же названием в той же компетенции заменяет «узнать», «проверить» и весь тест. Если в колонке «Уровень» стоит 1, 2 или 3, уровень тоже заменяется. Название в справочнике остаётся прежним.
